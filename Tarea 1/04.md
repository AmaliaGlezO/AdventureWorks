# Tarea #1: Especificación de Parámetros de Análisis y Filtros

Este documento define los parámetros, dimensiones de corte y criterios de filtrado que permitirán a los usuarios finales y directivos interactuar de forma flexible y dinámica con el almacén de datos para respaldar las decisiones **D2 (Lanzar una oferta especial para un producto)** y **D6 (Incrementar precios)**.

---

## 1. Parámetro de Análisis Temporal (Dimensión Tiempo / `DimDate`)

El análisis temporal es indispensable para comparar el comportamiento de las ventas en escenarios "antes y después" de la implementación de una oferta o una modificación en los precios.

* **Niveles de agregación:**
  * **Año (`CalendarYear`):** Permite comparativas interanuales de tendencia general.
  * **Trimestre (`CalendarQuarter`):** Útil para evaluar el rendimiento estacional de las promociones.
  * **Mes (`MonthNumberOfYear` / `EnglishMonthName`):** Granularidad principal para medir el impacto inmediato de ofertas de corta duración o ajustes de precios.
  * **Fecha exacta (`FullDateAlternateKey`):** Para análisis a nivel de día específico durante eventos promocionales.

* **Filtros requeridos:**
  * **Rango de Fechas (Fecha Inicio - Fecha Fin):** Permite aislar con precisión la ventana temporal en la que estuvo vigente la oferta especial (D2) o el momento exacto en que entró en vigor el incremento de precio (D6).
  * **Período Comparativo:** Opción de seleccionar un período base para realizar comparaciones intermensuales ($MoM$) o interanuales ($YoY$).

* **Justificación de Negocio:** Permite responder si las ventas aumentaron o cayeron durante y después de la aplicación de las decisiones estratégicas.

---

## 2. Parámetro de Clasificación de Producto (Dimensión Producto / `DimProduct`)

Permite segmentar el catálogo de artículos comercializados por AdventureWorks para determinar en qué líneas o artículos específicos las medidas tuvieron mayor o menor eficacia.

* **Jerarquía de Análisis:**
  
  $$\text{Categoría} \longrightarrow \text{Subcategoría} \longrightarrow \text{Producto}$$

* **Atributos de Filtrado:**
  * **Categoría de Producto (`EnglishProductCategoryName`):** (Ej. *Bicycles, Components, Clothing, Accessories*).
  * **Subcategoría de Producto (`EnglishProductSubcategoryName`):** (Ej. *Mountain Bikes, Road Bikes, Touring Bikes*).
  * **Nombre de Producto (`EnglishProductName`):** Identificación unívoca del artículo.
  * **Rango de Costo Estándar (`StandardCost`):** Filtro por margen/costo de fabricación para aislar productos de mayor o menor rentabilidad.

* **Justificación de Negocio:** Indispensable para medir el impacto de la oferta o aumento de precios a nivel de categoría completa o por producto individual.

---

## 3. Parámetro Geográfico y Comercial (Dimensión Territorio y Cliente / `DimTerritory` & `DimCustomer`)

Permite identificar variaciones en la sensibilidad del mercado según la ubicación geográfica del cliente o el canal de venta.

* **Jerarquía Geográfica:**
  
  $$\text{Grupo de Territorio (América del Norte, Europa, Pacífico)} \longrightarrow \text{País} \longrightarrow \text{Región/Estado}$$

* **Atributos de Filtrado:**
  * **País (`SalesTerritoryCountry`):** (Ej. *United States, France, Australia*).
  * **Grupo de Territorio (`SalesTerritoryGroup`):** Regiones comerciales globales.
  * **Tipo de Cliente (`CustomerType` / `CustomerMarket`):** Segmentación entre Venta al por Mayor (*Reseller*) y Venta Individual (*Direct Consumer*).

* **Justificación de Negocio:** Ayuda a identificar en qué zonas geográficas una subida de precios causó contracción de demanda o en cuáles una oferta especial tuvo mayor tasa de conversión.

---

## 4. Parámetro de Promoción y Oferta Especial (Dimensión Promoción / `DimSpecialOffer`)

Específico para el análisis de la decisión **D2 (Lanzar una oferta especial para un producto)**.

* **Atributos de Filtrado:**
  * **Tipo de Oferta (`SpecialOfferType`):** (Ej. *No Discount, Volume Discount, Excess Inventory, New Product*).
  * **Categoría de la Oferta (`SpecialOfferCategory`):** Diferenciación entre ofertas dirigidas a consumidores finales (*Customer*) o a revendedores (*Reseller*).
  * **Rango de Descuento (`DiscountPct`):** Filtrado por magnitud del porcentaje de descuento otorgado ($0\%$, $10\%$, $20\%$, $50\%$).

* **Justificación de Negocio:** Permite evaluar qué tipo de promoción resulta más rentable en términos de incremento del margen neto de ganancia.

---

## 5. Resumen de Matriz de Parámetros vs. Decisiones

| Parámetro / Filtro | Decisión D2 (Oferta Especial) | Decisión D6 (Incrementar Precios) |
| :--- | :---: | :---: |
| **Rango Temporal (Fecha Inicio/Fin)** | **Crítico** (Vigencia de la oferta) | **Crítico** (Punto de inflexión del precio) |
| **Jerarquía de Producto** | **Crítico** (Producto ofertado) | **Crítico** (Producto ajustado) |
| **Territorio / Región** | Relevante (Efectividad regional) | **Crítico** (Sensibilidad regional de precio) |
| **Tipo de Oferta / Descuento** | **Crítico** (Clasificación de campaña) | No Aplica / Control (Sin Descuento) |
| **Segmento de Cliente (Reseller/Consumer)** | Relevante | Relevante |
